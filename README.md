# 🌸 MoodBloom (무드블룸) - 아기자기한 마음 정원 회고 다이어리

> **"두세 줄의 소중한 고백, 나만의 포근한 감정 정원으로 피어나다"**  
> 무거운 일기 쓰기의 부담을 덜고, 퐁실퐁실한 파스텔 감성과 귀여운 3D 꽃 캐릭터 요정들과 함께 매일의 마음을 돌보는 힐링 웰니스 웹 애플리케이션입니다.

🌸 **웹사이트 바로가기 (Live Demo)**: [https://cheoyes123.github.io/moodbloom-2/](https://cheoyes123.github.io/moodbloom-2/)

---

## 🍓 무엇이 달라졌나요? (아기자기한 감성 대변신)

1. **포근한 파스텔 데이 & 나이트 테마 (Cozy Pastel System)**
   - 차갑고 어두운 사이버 글래스모피즘에서 **따스한 봄날 아침 햇살(Day)** & **별빛 쏟아지는 꿈속 정원(Night)** 감성으로 전면 리뉴얼.
   - 마스킹 테이프, 스티커 도장, 퐁실퐁실 마시멜로 카드 UI 적용.
   - 따스한 다크초콜릿 브라운 타이포그래피(`Gowun Dodum`, `Jua`, `Gaegu`, `Fredoka`).

2. **8대 감정 꽃 요정 캐릭터 (3D Cute Botanical Companions)**
   - 🌻 **기쁨 · 해바라기 뽀송이**: 방긋 웃는 해님 꽃잎과 뺨의 분홍 볼터치, 공전하는 별빛 요정
   - 🍀 **평온 · 모찌 클로버**: 말랑말랑 옥빛 네잎클로버와 데굴데굴 아기 이슬
   - 💜 **불안 · 구름 라일락**: 몽글몽글 보랏빛 솜사탕 구름 속에서 빼꼼 고개 내민 아기 꽃
   - 💧 **슬픔 · 물방울 물망초**: 맑은 사파이어 물방울 요정과 폭신한 마시멜로 구름 쿠션
   - 🌷 **분노 · 불꽃 튤립 삐약이**: 볼을 빵빵하게 부풀린 귀여운 꼬마 불꽃 요정과 팝콘 스파크
   - ☁️ **번아웃 · 잠자는 민들레**: 폭신한 구름 베개 베고 새근새근 낮잠 자는 민들레 홀씨 요정
   - 💖 **감사 · 하트 로즈베리**: 다정하게 피어난 핑크 로즈 하트 튤립과 꽃잎 오라
   - ✨ **희망 · 별빛 프리지아**: 파스텔 무지개 링을 두르고 춤추는 레몬빛 별꽃과 꼬마별

3. **마스코트 '블루미(Bloomy)' & 물뿌리개 꽃피우기 의식 (Watering Ceremony)**
   - 사용자의 행동에 맞춰 말풍선으로 응원해 주는 귀여운 정원 정령 마스코트.
   - 2~3줄 회고 후 **"물뿌리개로 물주기 🚿"**를 누르면 쪼르르 물소리와 함께 꽃이 만개하고 축하 팡파레 멜로디가 연주됩니다.
   - 편지 봉투에 담긴 **"블루미의 다정한 마음 편지 💌"**와 5분 맞춤 리추얼 처방전 제공.

4. **미니어처 부유섬 디오라마 정원 (3D Floating Island Diorama)**
   - 푸른 잔디 언덕, 앙증맞은 흰색 울타리, 조약돌 징검다리, 팔랑거리는 파스텔 나비들.
   - 심은 꽃들이 귀여운 테라코타 도자기 화분에 쏙 들어가 정원에 배치됩니다.
   - 화분을 클릭하면 그날의 회고 다이어리가 펼쳐집니다.

5. **다꾸 감성 스티커 캘린더 & 감정 꽃 도감 (Flower Dex)**
   - 날짜마다 피어난 꽃 스티커가 콕콕 찍히는 플래너 캘린더.
   - 내가 모은 감정 꽃들을 한눈에 보고 3D로 미리 볼 수 있는 8대 감정 도감.

6. **100% 무의존성 Web Audio & 동화나라 오르골 자장가**
   - 톡! 퐁! 귀여운 버블 팝 효과음, 쪼르르 물뿌리개 소리, 팡파레 아르페지오.
   - 6대 힐링 사운드: **동화나라 오르골 자장가 🎵**, 숲속 포근한 단비 🌧️, 432Hz 싱잉볼 🧘, 파스텔 파도 🌊, 모닥불 🔥, 산들바람 풍경 🎐.

## 🚀 로컬 실행 방법

브라우저에서 `index.html`을 바로 열거나 로컬 웹 서버로 실행할 수 있습니다:

```bash
# Python으로 로컬 서버 실행
python -m http.server 8080

# 또는 npx serve
npx serve .
```

실행 후 브라우저에서 `http://localhost:8080`을 방문하세요.
